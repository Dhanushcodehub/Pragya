## 🌟 Overview

**NIPUN Intelligence** is a teacher-led, sub-skill adaptive diagnostic tool designed for Foundational Literacy and Numeracy (FLN). It enables classroom teachers to evaluate students' actual reading and math capabilities, providing actionable, non-ranking insights for instructional grouping.

---

## 🔒 Synthetic Data & Privacy Statement

This platform operates exclusively with **synthetic sample data** for classroom simulation and diagnostic demonstration. No personal identifiable information (PII) of actual children is collected or processed.

---

## ⚙️ Core Architecture Chassis

- **Frontend & App Framework:** Next.js (App Router), React, TypeScript
- **Styling & Tokens:** Tailwind CSS with custom cream design tokens
- **Authentication Backbone:** Supabase Auth (Client, Server, Middleware)
- **AI Assist Layer:** Gemini API (used exclusively for pedagogical explanation and diagnostic support)
